# employee-salary-pyspark-project
# Employee Salary Analysis using PySpark

## 📖 Project Overview
This project performs salary analysis on employee data using PySpark. 
It demonstrates data cleaning, aggregation, window functions, and Parquet storage.

## 🚀 Features
- Read CSV data
- Remove null salary values
- Department-wise salary aggregation
- Salary ranking using dense_rank()
- Highest salary per department
- Write output in Parquet format

## 🛠 Tech Stack
- Python
- PySpark
- Spark SQL
- Parquet

## 🧠 Concepts Used
- groupBy()
- Aggregations (sum, max)
- Window Functions
- dense_rank()
- partitionBy()
- DataFrame API
